# ResearchPilot

An evidence-grounded NLP assistant for asking questions about research papers and inspecting page-level citations.

## Goals

- Extract text while preserving PDF page metadata.
- Retrieve relevant passages with semantic search.
- Generate answers grounded in retrieved evidence.
- Validate citations and abstain when evidence is insufficient.
- Evaluate retrieval and answer quality reproducibly.

## Current Status

Phase 0 — project foundation.

## Planned Technology Stack

- Python
- PyMuPDF
- Sentence Transformers
- FAISS
- Hugging Face Transformers
- Gradio
- pytest

## Data and Privacy

No private PDFs, secrets, model weights, or large artifacts are stored in this repository.
